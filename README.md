# comunes

Librerias compartidas de la plataforma Panorama Legacy.

## Alcance
- `PanL`, `PanDat`, `OriWin` y `WinCom` como base transversal para modulos de negocio.

## Estructura base
- `src/`: carpeta reservada para estabilizacion gradual de codigo.
- `docs/`: documentacion tecnica y operativa.
- `build/`: scripts y salidas de build no versionadas.
